# 競艇予想自動化システム 設計書

参考にした2つのプロジェクト:
- metaboatrace … 公式サイト(boatrace.jp)のスクレイピングライブラリ`metaboatrace.scrapers`とデータモデル`metaboatrace.models`をPyPI公開しているOSS
- ポセイドン … 過去100万レース以上のデータから「海神指数」という独自指数を算出し、無料で予想を配信しているAIサービス

この2つの「型」を踏襲し、①データ収集は自作せず`metaboatrace.scrapers`に乗る、②予想は確率モデル×独自指数で出す、という構成にする。

## アーキテクチャ

cron / GitHub Actions (毎日 出走表確定後に起動)
1. collectors/ … metaboatrace.scrapers で 出走表・選手成績・モーター成績・直前情報(展示タイム/チルト/体重)・オッズ を取得
2. storage/ … SQLiteに正規化して蓄積(選手・レース・出走・結果テーブル)
3. features/ … 特徴量生成
4. models/ … LightGBMで「1着になる確率」を6艇分算出
5. betting/ … 3連単の買い目を鉄板/中穴/大穴に分類・配分
6. notify/ … Discord Webhook / コンソール / CSV出力

## テスト運用モード(14日間・30レース/日)

モーニング/デイ/ナイター各10レース、1レース1000円・5〜8点で運用する。
GitHub Actionsが1日6回(各セッションの予想+結果確定)を自動起動する。
